# QA Case Study: AI-Generated Skills Game

**Project:** AI-Generated Skills Game  
**Application Type:** Mobile Application  
**Role:** Software Quality Assurance Engineer  
**Testing Focus:** Functional, UI, Regression, and User Interaction Testing

## 1. Project Overview

The AI-Generated Skills Game is a gamified mobile learning platform designed to help users develop skills through interactive, text-based challenges and game-like progression.

The platform combines learning activities with features such as multiple question formats, points, levels, leaderboards, social sharing, and notifications to support an engaging user experience.

The project description also identifies AI-generated challenges and supporting images as platform capabilities.

## 2. Key Platform Features

- **Interactive Learning Challenges:** Skill-based challenges presented to users.
- **Multiple Question Formats:** Multiple-choice questions (MCQs), fill-in-the-blanks, and text-answer activities.
- **Gamification:** Points, levels, leaderboards, and rewards.
- **Social Sharing:** Sharing functionality for platforms such as WhatsApp, Facebook, and Twitter.
- **Notifications:** User engagement and activity notifications.
- **AI Capabilities:** AI-generated text challenges and supporting images.
- **Admin Panel:** Analytics, user management, and AI performance monitoring.

## 3. My QA Responsibilities

### Functional Testing

- Tested application functionality and user-facing workflows.
- Checked interactions across relevant learning and gameplay features.
- Validated expected behavior during supported user journeys.

### UI Testing

- Reviewed the mobile application's interface and presentation.
- Checked UI behavior and identified inconsistencies affecting the user experience.

### Question and Answer Workflow Testing

- Tested multiple-choice question (MCQ) workflows.
- Tested fill-in-the-blanks activities.
- Tested text-answer interactions.
- Checked the expected behavior of the different learning activity formats.

### Notifications and Social Sharing

- Tested notification functionality.
- Validated social-sharing interactions involving supported sharing options.

### Regression Testing

- Rechecked relevant application functionality during testing cycles.
- Checked existing workflows for unintended issues following changes.

### Defect Reporting

- Documented identified defects with reproducible steps and clear expected versus actual behavior.
- Communicated findings to support defect investigation and resolution.

## 4. Testing Approach

My testing activities focused on the application's main learning interactions and supporting mobile functionality.

The areas covered included:

1. General functional workflows.
2. Mobile UI behavior.
3. MCQ, fill-in-the-blanks, and text-answer activities.
4. Notification functionality.
5. Social-sharing interactions.
6. Regression checks.
7. Defect identification and reporting.
